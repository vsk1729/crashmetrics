# Disclaimer and trademarks

## Engineering disclaimer

crashmetrics is an engineering calculation aid. Users must independently
validate numerical results and confirm that input processing, filtering,
sampling and calculation methods match the applicable assessment
protocol. The software does not certify regulatory compliance, and its
results are not official ratings. See [Protocol notes](../protocol-notes.md)
for every interpretation the package makes, and [Validation](../validation.md)
for what each function is checked against and what is not validated yet.

## Sources

Formulas and limits are taken from publicly available documents:
Euro NCAP assessment and test protocols (including CP 005 and CP 007),
Bharat NCAP AIS-197, AIS-100, UN Regulations No. 94 and No. 127, UN GTR 9,
FMVSS 208, SAE J211 and the published research cited in the API
reference. No protocol text is reproduced beyond section numbers, limit
values and a few short quoted phrases in the protocol notes, where the
exact wording decides an interpretation.

crashmetrics is an independent open-source project. It is not affiliated

The test-versus-CAE ratings are independent implementations of
published methods: ISO/TS 18571 from the standard's published
description and parameters (no text of the standard is reproduced), and
the corridor and cross-correlation (CC) rating from Gehre, Gades and
Wernicke (ESV 2009), the method used in PDB's CORA tool. No code or
documentation of those tools is included. The ISO/TS 18571 results were
compared with TU Graz's MIT-licensed `objective-rating-metrics`; only
computed numbers from it are used in the tests.

The LS-DYNA readers were written from the text layout of output files;
no LS-DYNA code or documentation is included. The keyword deck reader
(`crashmetrics.deck`) was written from the keyword file format itself;
no code of other keyword readers (open-source or not) was used or
consulted for it. The binout reader (`crashmetrics.binout`) was written
from the binary layout of binout files, worked out from public files
whose values were checked against the ASCII files of the same runs; no
code or documentation of other binout readers (open-source or not) was
used. The real output files and decks in the repository's
test data come from MIT-licensed projects (K-agent,
helmet-fit-bayes-opt, dyna_pladebuk, LS-PrePost-MCP, pyisomme), each folder with its
licence file and a README naming the source and commit. Files whose
licence is not MIT or is unclear are only checked locally and are not
included. The example runs of `crashmetrics.synthetic` are generated by
the package and say so in their header.
